# 🌾 Crop Recommendation System

This project uses machine learning to recommend the most suitable crop to grow based on environmental and soil parameters. It helps farmers and agriculturalists make informed decisions for higher productivity and sustainable farming.

---

## 🚀 Features

- Predicts the best crop using environmental factors like nitrogen, phosphorus, potassium, temperature, humidity, pH, and rainfall.
- Utilizes multiple machine learning models (Random Forest, KNN, Decision Trees, etc.).
- Data visualization and model evaluation.
- Interactive Jupyter Notebook.

---

## 🧠 Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Seaborn, Matplotlib
- Jupyter Notebook
